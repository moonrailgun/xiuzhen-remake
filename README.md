# 《修真》本地怀旧版

2008 年网页游戏《修真》（广州昆冈开发、广州游艺运营，`xz.yyge.com`，2011-02-21 停运）的本地单机复刻。

游戏本体一点没留下——服务端、客户端脚本、原始美术素材全部无存档。这个复刻建立在考据之上：
160 多张真实截图、250 多段玩家粘贴的原版页面 HTML、44 场真实战报、官方攻略与指南原文。

## 玩

```bash
npm install
npm run dev     # 打开 http://localhost:5273
```

首次打开是建号页。建完号就能升经脉与法术、看地图、走路、领任务、炼器、淬炼、出击打人、
买卖真气、进城镇投资、翻游戏指南。七个主标签全部接真实存档。
建号 10 天（或道行满 18 年）出保之后，附近的「狼」会打过来——护身先接战，
守不住就被抢走暗仓以外的真气并被击退，和当年一样。
关掉浏览器再打开，离线期间的进度会按游戏时钟补算。顶栏「关于」可以调倍速、导入导出存档。

**端口固定 5273**：存档按 origin 隔离（含端口），换端口会让存档「消失」。

## 开发

```bash
npm run check      # 类型检查 + 单元测试
npm run playtest   # 端到端试玩 58 步（需先 npm run dev）
npm run regression # 正式入口的任务、存档、经济、战斗回归（需先 npm run dev）
npm run smoke      # 全页面冒烟（需先 npm run dev）
npm run parity     # 截图对齐检查（需先 npm run dev）
```

使用 Node.js 24。`check` 和 `build` 不依赖参考归档；缺少本地资料时，原文和出处文件的核对测试会明确跳过。
重新裁切素材、解析原始战报或核对原版截图，需要自行保留对应的本地归档。

## 目录

```
src/
  engine/      纯规则，无 DOM：时钟、事件时间线、战斗、修炼、移动、市场、城镇、NPC、存档
  data/        数值表，每条带出处或标 reconstructed
  pages/       一条原版路由一个文件，DOM 结构/class/图片名沿用原版
  client/      app 接引擎、vm 做状态→视图投影、windows 对应原版 window/timer
public/        游戏运行所需的样式与图片
tools/
  assets/      素材流水线（裁切 + 程序化生成）
  parity/      截图对齐与端到端试玩
  fixtures/    从原始资料解析出的回归数据
```

`reference/`（原版 HTML、截图、论坛帖、APK 等）与 `docs/`（研究底稿、设计与开发记录）
仅保存在本地，由 `.gitignore` 排除。代码中的出处路径保留，供持有归档的人核对；仓库不包含这些资料。

## 哪些是还原，哪些是重建

完整台账保存在本地 `docs/PLAN.md` §3。简要说：

**照原版**（有原文、原版 DOM 或 1:1 截图）
建号页逐字、页面框架与六种浮窗、地图几何与数据协议、战报与推算结果的格式文案、
战斗事件总览的四种标题句、游戏指南四条词条、镖局老板对话、
战斗规则（敏捷=缠斗秒数、断剑判定、相生加半、相克 ×150%）、14 把飞剑的完整数值、
产量公式与道行定义、移动耗时、开服日历、保护期、新手任务 22 步、百妖记 97/100 回、
十二正经的分组与五行映射。

**按推断**（有锚点，插值或反推）
品质倍率与淬炼 2^N、经脉倍率曲线、丹田容量、固本暗仓、升级与炼制消耗的五行配比、
伤害分摊（用 6944 条真实战报回归定型）、九州方位。

**补写并标注**（机制有据、文案或个别数值无存档 —— 界面上标明不是原文）
游戏指南 18 条词条、四种术数的结果表、五个城镇 NPC 的对话、三阴绝脉剑的炼制数值。

**只能重建**（无证据，代码里标 `reconstructed`）
经脉/本体/法术的逐级消耗曲线、世界地形分布、整个 NPC 生态与门派、
出击选剑页与战场地图、护法页、游戏指南其余 18 条词条、
镖局以外的城镇 NPC 对话。

## 证据强度

关键回归用的是真实原版数据：

- **6944 条飞剑战报记录**——两条不变量零反例（受到伤害 ≤ 耐久；等于耐久 ⇔ 惨被斩断）
- **原版 `mapData` 的 113 格坐标**——我们的屏幕坐标公式逐格吻合
- **14 把飞剑的原版物品窗**——与三张截图的极品数值逐项对照
- **建号页原版 HTML**——本地有归档时，测试直接读 GBK 原文比对文案与取值

## 不确定的地方

拿不准的数值在源码里保留出处或 `reconstructed` 说明。
更完整的依据、缺口与替换方法保存在本地 `docs/UNCERTAIN.md`，不随源码发布。

## 边界

- 名称、文案、美术版权归广州昆冈与广州游艺，攻略原文归当年的玩家。
- 本项目用于个人本地怀旧。原始参考归档不随源码发布；运行素材中仍有原版截图裁切，来源见 `tools/assets/README.md`。
- 资料里 2008 年的客服电话、QQ 群、个人联系方式均未带入游戏。
- NPC 生态是重新设计的，不是还原——原版一半的乐趣来自真人互抢，单机下只能模拟。
- 数值只能做到「节奏像」，无法证明「相等」。所有数值都在数据文件里，可整表替换。
