# 素材清单（`manifest.json`）

`public/` 已包含运行所需素材。以下裁切、重建和对账脚本需要本地 `reference/`、`docs/` 归档，这些资料不随源码发布。

阶段 0 产物。原版的 CSS/JS/图片本体**全部 0 存档**（`07 §5/§6` 用两种方法、三种粒度复查过），
我们只有 **120 个原版文件名** 和 **159 张截图**。这份清单把每个文件名落到「怎么把它做出来」的四档之一。

- 清单：`manifest.json`，一个 JSON 数组，每项 `{path, tier, purpose, source, bbox, method, issues, confidence}`。
- 对账脚本：`python3 tools/assets/check.py` —— 07 §7.2 的文件名少归类一个就报错（PLAN §3 要求的「缺一个脚本报错」）。

```
07 §7.2 文件名全集：120 个，已归类 120 个，未归类 0 个
清单条目：200（含 80 条原版未实见、按命名规律补的推断项）
各档数量：A=13  B=33  C=128  D=26
对账通过。
```

## 字段

| 字段 | 说明 |
|---|---|
| `path` | **原版路径与文件名**，也就是复刻时要落盘到 `public/` 下的路径。带 `[文件名推断]` 字样的（见 `issues`）是原版未实见、按命名规律补的 |
| `tier` | `A`/`B`/`C`/`D`，见下 |
| `purpose` | 这张图在原版界面里干什么、什么尺寸 |
| `source` | 来源截图 `reference/images/... (#编号)`（编号见 `reference/images/_contact-sheets/index.json`）。A/B 必填；C/D 写 `null`，或写「占位来源 / 本清单内的上游产物」 |
| `bbox` | `[x, y, w, h]`，**在该来源原图的像素坐标系里**。A/B 必填，C/D 恒为 `null`。误差写在 `issues` 里（多数 ±2px，水墨软边与反推原点的 ±4px） |
| `method` | 具体做法 |
| `issues` | 质量问题：JPEG 噪点、被遮挡、水印压住、只有缩放图、文件名推断…… |
| `confidence` | `high` 规格已实测 / `medium` 有样张但有噪声或需推断 / `low` 无证据、自创或占位 |

### 一条硬约束

**执行者是 AI 代理，不会手绘水墨。**
所以「必须重绘」的水墨类素材只允许进 **C**（有可程序化的规格）或 **D**（占位），
**绝不允许挂在 B 上指望后面手绘**。B 档的每一条都必须是「裁像素 + 脚本修补」能完成的。

## 几条写死的做法

- **地块只做一套**：`img/map/` 的 11 个基础块（视野外态）程序化画一次，
  `*blue`（视野内）/`*green`（可移动范围）两套 22 个文件由**同一个调色脚本**派生，**不裁三遍**。
  语义来自 map.jsp 整页 `mapData` + 曼哈顿距离统计（06 §1.4）：`green` 地面偏灰地物最深、
  `blue` 地面淡蓝白地物正常、无后缀地面近白地物褪色（基准期取去色）。
- **人体也只做一套**：2 张线稿（B）→ 调色脚本派生 10 张五行着色（C）+ 2 张金丹全黑剪影（C）；
  经脉/本体节点圆盘与丹田光球不入图，用 CSS `radial-gradient` 叠加。
- **页标题横幅**：7 张有 1:1 裁片的直接裁（B）；其余 7 张用已裁横幅的空白段做墨刷底 + 楷体渲染两字合成（C）。
  合成件的字形与原版行楷必然不同 → 截图对齐验收时对这些图**打掩膜**。
- **去噪原则**（PLAN §3）：像素小件裁切后量化；水墨与渐变**保留灰度、只去 JPEG 块噪、不做阈值化**；
  HiDPI 下像素件用 `image-rendering: pixelated`，水墨件先保持 1×。

## 与 PLAN §3「美术四档」初版的 4 处不同（都写在这里备查）

PLAN §3 是初版草稿，本清单按任务书给的四档定义重新判定，有 4 处收紧/放宽：

| 项 | PLAN 初版 | 本清单 | 理由 |
|---|---|---|---|
| `btncancel.gif`、`btn/about.gif` | D 占位 | **C** | 任务书把「按钮」明确列为 C；这两个按钮与另外 8 个共用同一套通式（米灰底 + 深灰褐边 + 回纹折角 + 12px 宋体），只是文案不同，脚本一行参数的事，比占位更准 |
| `titlerank.gif`（排行榜横幅） | D（只有缩放图） | **C** | 有墨刷底（从 B 档裁片取）+ 字体渲染这条可程序化路径，比放大 0.89 倍的 JPEG 好；同一个合成脚本还顺带覆盖了地图/消息/创建人物/战斗事件/秘笈 5 张 |
| 村庄 / 小镇 / 城池地块 | D | **C** | 有画面描述 + 褪色样张，64px 像素风可程序化；福地/九州/五岳仍是 D（零截图零描述） |
| 女·土 / 男·水 剪影、女金丹剪影 | D | **C** | 渐变填充色是**按五行取的、与性别无关**（04 §9.3 给了 5 套色），一套调色脚本覆盖 10 个组合；只在 `issues` 里标明这两个组合没有截图可比对 |

D 档因此收窄为一条判据：**无任何 1:1 截图、且无可程序化复现的规格描述**
（附加一条：只有低倍缩放的高频水墨纹理，放大后不可用，同归 D —— 只有昆仑荷水印一项）。
